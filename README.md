## Featured Project: DhakaRoadNet EdgeAI

**DhakaRoadNet** is an end-to-end Edge AI road-object detection project for Dhaka urban traffic. It covers the full path from real road data collection to YOLOv8 training, TensorFlow Lite export, and native Android deployment.
